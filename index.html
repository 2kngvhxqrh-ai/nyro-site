The idea

Most assistants are one enormous prompt. This one is small parts that load only when they match, so the context stays clean and the instructions never compete with each other.

The constraint that shapes everything: you have to be able to read everything it knows in a text editor, with nothing running. No database, no proprietary index. That rules out a lot of convenient designs, and it is why memory is folders of .md files with YAML frontmatter and wikilinks rather than anything cleverer.

Install

One command, and it defaults to a dry run that writes nothing:

npm run setup
npm run setup -- --yes

It never overwrites an existing vault page and never downloads without --yes. Re-running tops up what is missing and reports what it left alone — verified by editing a page, deleting another, and running it again.

Where a platform has no prebuilt binary it prints that platform's install command rather than failing, or worse, appearing to succeed.

Voice loop

Hold the key, speak, release. Speech-to-text and text-to-speech both run on the CPU — no audio is uploaded, which is the part browser speech APIs get wrong.

01 — CAPTURE

ffmpeg records to 16 kHz mono, the rate whisper wants, so nothing resamples later. The device is detected at startup.

dshow · avfoundation · alsa
02 — TRANSCRIBE

whisper.cpp. Recording is stopped with q, never a kill — a killed ffmpeg leaves a truncated header.

ggml-base.en · 4.2× realtime
03 — ANSWER

The text goes to Claude Code, so speaking reaches the same skills typing does. Falls back to local agents when signed out.

claude -p
04 — SPEAK

Piper reads the answer back. Markdown is stripped first — asterisks and backticks are for eyes.

Skill layer

One job each. The description carries the trigger, so the right one fires without being named — and the boundaries are drawn so two never fire on the same sentence.

vault Reads and writes the markdown vault. Every other skill persists through it, so exactly one place knows the schema. "save this" · "what did I decide about X"
plan Today's three priorities to a dated file. Carries unfinished items forward and flags anything carried three days running. "what should I work on"
inbox Mail and calendar filtered to what is time-bound, blocking someone, or expensive to keep ignoring. Reports fewer than three rather than padding. "what's on today" · "what did I miss"
trends Scans a watchlist and diffs against the last scan. A story that has not developed is not repeated. "what's new" — never "what is X"
metrics Tracked numbers with the change since last time. An unconfigured source reports as unconfigured, never as zero. "how are my numbers"

Vault

Three folders, and the distinction between them is the whole design: raw is what was said, wiki is what is now believed, outputs are what was sent. Collapsing them is how a notes system becomes a junk drawer.

raw/

Unedited capture — transcripts, dumps, clippings. Dated, because raw material is found by when it arrived.

wiki/

Distilled knowledge, one page per topic, rewritten in place. No date in the filename: a dated wiki page means the topic got forked instead of updated.

outputs/

Everything the system ships. Always dated, never rewritten — tomorrow's brief is a new file, not an edit of today's.

One finding worth keeping: room noise comes back from whisper as (dramatic music), not as silence. Left unfiltered, an empty room sends that onward as a prompt.

What runs where

The vault, skills and HUD are plain Node and run anywhere. The voice layer has one real limit, stated rather than papered over.

Windows

Everything, including hold-to-talk on a global keyboard hook.

macOS · Linux

Everything except the global hotkey. Enter starts, Enter sends — the same signal file, so nothing downstream can tell the difference.

Why

A low-level keyboard hook off Windows needs a native module or permissions an installer cannot grant. A feature that quietly does nothing on your platform is worse than one that tells you what it is.

The subtle one: macOS lists video and audio devices under the same [0]/[1] indices in a single listing, video first. Parsing it whole records the webcam — and it does not error, it captures silence from the wrong device. There is a test asserting exactly that.

Still open

Mail has no working path

There is no Gmail connector, so the only route is a Google OAuth client of your own — a console step, then a device-flow sign-in. Calendar already works through a connector; mail does not. Until then the brief runs on calendar, tasks and the vault, and says so rather than quietly returning a short list.

The voice loop prefers Claude Code and falls back to local agents when it is signed out, so it answers either way — narrower when local, but never dead.
